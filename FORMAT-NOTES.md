# Format Notes

This package aligns with the repository style:

- Agents use `.md` files with YAML frontmatter plus Markdown body.
- Skills use directory-based `SKILL.md` files.
- Rules are added as standalone `.md` files under `.claude/rules/`.
- Text examples/checklists are normalized to Markdown where appropriate.
- No `.txt` files are used for agents, skills, or rules.
