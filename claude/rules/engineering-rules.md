# Engineering Rules / 工程通用规则

## Scope and consistency
- Understand the task before editing.
- Keep changes minimal, scoped, and traceable.
- Prefer consistency with the existing codebase.
- Do not introduce unrelated refactors.
- Do not present pseudo code as complete implementation.

## Change control
- Identify affected modules/files before editing.
- Preserve backward compatibility unless explicitly allowed to break it.
- For medium or large work, separate API, backend, frontend, SQL, test, and docs impact.

## Delivery expectations
- Update tests for meaningful behavior changes.
- Update docs when API, behavior, SQL, setup, or usage changes.
- Summaries must distinguish completed work, deferred work, and risks.

## Communication
- Chinese is fine for daily collaboration.
- Keep technical identifiers stable in English.
- Mixed Chinese + English is preferred where it improves clarity.
