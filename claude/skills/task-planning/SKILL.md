# Task Planning / 任务规划

## Required planning dimensions
- goal
- scope
- assumptions
- affected modules/files
- API impact
- SQL impact
- tests
- docs
- risks
- rollout / rollback concerns

## Rules
- separate planning from coding
- plans should be specific and executable
- avoid vague task decomposition
