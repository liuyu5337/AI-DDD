# Task Planning Rules / 任务规划规则

When planning, always include / 规划时必须包含:
1. Goal and value / 目标与价值
2. Scope and non-goals / 范围与非目标
3. Assumptions / 假设
4. Backend impact / 后端影响
5. Frontend impact / 前端影响
6. API impact / 接口影响
7. SQL impact / SQL 影响
8. Test impact / 测试影响
9. Documentation impact / 文档影响
10. Risks and execution order / 风险与执行顺序

For medium or large tasks, split into / 中大型任务明确拆成:
- API design
- backend implementation
- frontend implementation
- SQL changes
- tests
- documentation
