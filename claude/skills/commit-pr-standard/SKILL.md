# Commit and PR Standard / 提交与 PR 规范

## Commit
- one logical change per commit where practical
- concise but explicit message
- avoid meaningless messages like update/fix/test unless qualified

## PR
- describe scope
- describe risk
- mention tests
- mention docs / SQL impact
