# Frontend Rules

## Baseline
- Vue 3
- Composition API
- Element Plus

## Rules
- Keep views focused on composition.
- Avoid heavy business logic in templates.
- Centralize API calls.
- Prefer reusable components for repeated patterns.
- Make loading, empty, and error states explicit.
- Keep labels, placeholders, and messages consistent.
- Use clear form validation and confirmation for destructive actions.
